# SmartClean Data

> Préparation et nettoyage de données IoT issues de bâtiments intelligents pour le Machine Learning.

## Description

Ce projet consiste à nettoyer et préparer un jeu de données provenant de capteurs IoT installés dans des bâtiments intelligents.

Les données contiennent différents problèmes de qualité : valeurs manquantes, doublons, valeurs aberrantes, incohérences, variables catégorielles et échelles différentes.

## Objectifs

- Explorer et comprendre les données
- Identifier et corriger les problèmes de qualité
- Traiter les valeurs manquantes et aberrantes
- Encoder les variables catégorielles
- Standardiser les variables numériques
- Éviter les fuites de données
- Construire un pipeline de preprocessing avec Scikit-learn
- Exporter un dataset prêt pour le Machine Learning
